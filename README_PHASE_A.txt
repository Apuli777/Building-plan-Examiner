BUILDPERMIT PORTAL — PHASE A

1. Extract this ZIP to a normal project folder, e.g. C:\Projects\BuildPermit_Phase_A.
2. Open that extracted folder in VS Code: File > Open Folder.
3. Open Terminal > New Terminal. Confirm the terminal path is the project root (the folder containing package.json).
4. Run: node -v
5. Run: npm -v
6. Run: npm install
7. Run: npm run dev
8. Open http://localhost:5173 if it does not open automatically.

Phase A is only project setup and design system. Phase B will replace the temporary App.jsx preview with routing and application state. Do not add backend/database code now.
